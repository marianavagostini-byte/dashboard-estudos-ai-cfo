# Histórico de exercícios realizados

Este índice registra somente exercícios efetivamente realizados. Ele é separado do progresso de cursos no dashboard: criar ou receber um exercício não o adiciona ao histórico nem conclui uma etapa.

O histórico Git disponível foi inspecionado durante a configuração e contém a aplicação, documentação e capturas de tela, mas não identifica exercícios de prática realizados. Por isso, não há entradas confirmadas para registrar neste momento. Isso não significa que nenhum exercício tenha sido feito fora deste repositório.

| Data | Assunto | Arquivo (caminho no repositório de prática) | Resultado dos testes observado | Hash do commit |
|---|---|---|---|---|

Adicione uma linha somente após confirmar a realização e os dados correspondentes. Não preencha data, resultado ou hash por inferência; se não houver commit ou testes, deixe esses campos sem valor ou use `não informado`.
